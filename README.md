# 宰执春秋（Prime Minister Simulator）

> 一款以总理执政为核心的政治决策模拟游戏。你将扮演一国总理，在 48 个月的任期内管理国家指标、应对议会质询、推进改革立法、处理外交危机，争取连任与青史留名。

**版本**：1.2.1
**开发者**：prideplayer
**技术栈**：Electron + Vite + React + TypeScript + Zustand + Tailwind CSS + motion/react

---

## 特色

- **六项国家指标 + 19 项二级细分**：民意、国库、经济、稳定、外交、声望，每月自动推导二级指标，仪表盘可展开查看从属关系
- **41+ 项改革链**：覆盖经济、社会、环境、政治体制、军事、文化六大领域，改革有前置链与解锁政策
- **44+ 事件 + 7 道德困境 + 7 紧急事件 + 3 入侵事件 + 5 倒计时事件**：每 25 天触发普通事件，指标阈值触发紧急事件，复杂条件触发入侵
- **议会质询卡牌系统**：每 60 天自动触发，拖拽卡牌应对质询，成功加威望失败扣民意
- **法案表决密室政治**：6 种法案类型，拉票、施压、妥协争取过半赞成票
- **13 封选区信件 + 13 份外交照会**：每 90 天收信、每 120 天收照会，选项抉择影响指标
- **内阁聊天系统**：6 位初始部长，每 75 天主动私信附带选项，需回应避免背叛
- **组阁要求追踪**：6 个执政党各有组阁要求，未落实会触发最后通牒甚至辞职
- **8+ 成就 + S/A/B/C/D 五档评级**：成就使用持久状态追踪，困难难度下阈值更高
- **国家代入感叙事**：20+ 条叙事节拍按执政阶段触发，仪表盘每日简报根据局势动态生成
- **新手引导式教程**：16 步逐步引导，自动跳转页面 + 高亮关键元素，含法案表决密室政治
- **右侧待办提示栏**：19 类待办实时追踪（含 8 类鼓励性建议），红/橙/蓝三色分级，左键跳转/右键忽略/可收纳，悬停看详情
- **两档难度**：普通难度显示数值提示，困难难度隐藏部分提示并缩放加成
- **三层导航架构**：顶部主导航 + 右侧图标栏（悬停展开）+ 右侧滑出面板，全程快捷键支持

## 快速开始

### 环境要求
- Node.js ≥ 18
- npm ≥ 9

### 安装依赖
```bash
npm install
```

### 开发模式
```bash
npm run dev
```
启动 Vite 开发服务器，Electron 自动打开应用窗口，支持热更新。

### 类型检查
```bash
npx tsc --noEmit
```

### 构建生产版本
```bash
# 仅构建前端
npm run build

# 打包桌面安装包（Windows NSIS）
npm run build:win
```
打包产物位于 `build-out-v2/` 目录，含 `宰执春秋 Setup <version>.exe` 安装器与 `win-unpacked/` 免安装版。

### macOS / Linux
```bash
npm run build:mac    # 打包 macOS（需在 macOS 上执行）
npm run build:linux  # 打包 Linux
```
macOS 未签名打包，用户首次打开需在"系统设置 → 隐私与安全性"中允许运行。

## 玩法速览

### 开局流程
1. **主菜单** → 新游戏
2. **角色创建**：姓名 + 背景（3 选 1）+ 特质（5 项滑块）+ 难度（普通/困难）
3. **组阁谈判**：与盟党谈判组建执政联盟（需过半席位）
4. **初始内阁**：从候补任命 6 位部长
5. **新手教程**：首次自动引导（可跳过）
6. **正式执政**：时间流动，开始决策

### 核心循环
```
推进时间 → 事件触发 → 玩家决策 → 指标变化
    ↓                                   ↓
月末结算 ←←←←←←←←←←←←←←←←←←←←←←←←←←←
    ↓
改革结算 + 内阁加成 + 自然衰减 + 执政党耐心衰减
    ↓
检查结局（大选 / 提前下台 / 主动辞职）
```

### 关键操作
- **空格**：暂停/恢复时间
- **D/F/T/P/I/O/M/E/S/N/W**：跳转主导航页面
- **L/B/R/A/X/V/C**：打开右侧面板（议会/民意/内阁系列）
- **右上角菜单**：百科、存档、设置、**开发者选项（二次确认）**、退出

> **v1.2.2 变更**：开发者控制台不再通过 `~` / `` ` `` 键呼出。改为右上角"菜单" → "🛠️ 开发者选项" → 二次确认进入，避免误触。

### 新手教程触发
- **首次进入游戏**：未完成教程时自动弹出（可跳过）
- **手动立即触发**：右上角菜单 → 设置 → "▶ 立即重看新手教程"
- **演示/调试入口**：右上角菜单 → 开发者选项（二次确认）→ "▶ 立即重看新手教程"
- 教程可在游戏中随时重看，不影响成就判定

### 结局目标
- **S 级**：六项指标均值 ≥85，"青史留名"
- **连任三届**：执政 12 年以上，"三朝元老"
- **专项成就**：经济奇迹、外交大师、满堂喝彩、不倒翁

## 技术亮点

- **Electron + React + TypeScript**：跨平台桌面应用，类型严格
- **Zustand 单一全局状态**：30+ actions 封装所有副作用
- **纯函数引擎层**：`GameState → GameState`，便于测试与回放
- **motion/react 动画**：页面切换、卡牌拖拽、面板滑出等流畅过渡
- **Tailwind CSS**：原子化样式，深色羊皮纸主题
- **NSIS 安装器**：含图标缓存刷新脚本，解决安装后桌面图标不更新问题
- **存档系统**：手动 + 自动（每 15 分钟），自动存档保留最近 5 个

## 通用化设定

为避免具体国家属性，游戏采用通用化设定：
- 国名由玩家自定义或使用默认"共和国"
- 总统随机生成姓名，60% 概率与总理同党
- 邻国使用通用化称谓，无具体国名
- 事件文案已移除"长江"等具体地名，改用"流域"、"南部多省"等通用表述
